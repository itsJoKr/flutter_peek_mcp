## Running the example app

When I ask you to run the app (for example, "run this on my mac"), run the
example app in `example/aisle` in debug mode, in the background, and always
with `--vmservice-out-file`:

```bash
cd example/aisle
flutter run -d macos --vmservice-out-file=/tmp/flutter_peek_vmservice.txt
```

When that is all I ask, start the app and stop there.
